## ✦ Visão geral

O **Projeto Gráfica** celebra o acabamento imperfeito e vivo da impressão manual: papel creme, rosa fluorescente, azul intenso, textura pontilhada e tipografia com desalinhamento proposital de registro.

O site é estático, responsivo e sem dependências de build. Foi feito para apresentar impressões, tintas, trabalhos recentes, oficinas e o estúdio de forma direta, visual e autoral.

## ⚡ Experiência

| Camada | O que acontece |
| :-- | :-- |
| **Tipografia riso** | Títulos rosa e azul sobrepostos criam o efeito de duas tintas fora de registro. |
| **Textura** | Uma camada fixa de pontilhado traz a sensação de papel e tinta impressa. |
| **Duotone** | Fotos começam em azul e rosa; no hover, revelam suas cores originais. |
| **Navegação** | Em telas pequenas, o botão Menu abre uma navegação em tela cheia. |
| **Interações** | Cards, tintas e itens do portfólio respondem ao cursor com movimento e contraste. |

## 🚀 Começar

1. Clone este repositório.
2. Abra a pasta no VS Code.
3. Inicie o `index.html` com a extensão **Live Server**.
4. Acesse `http://127.0.0.1:5501` no navegador.

> Não há instalação, framework ou etapa de compilação: é só abrir e imprimir.
