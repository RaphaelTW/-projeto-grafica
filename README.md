# Projeto Gráfica

Landing page estática para um estúdio independente de risografia e serigrafia.

O conceito visual usa papel creme, tinta rosa fluorescente, azul intenso e textura de impressão. A página apresenta serviços de impressão, paleta de tintas, processo de produção, portfólio, oficinas e informações do estúdio.

## Estrutura

```text
.
├── index.html
└── src
    ├── css/style.css
    ├── img/print-studio-contact-sheet.png
    └── js/script.js
```

## Como visualizar

Abra `index.html` no navegador ou use a extensão Live Server no VS Code (porta `5501`). Não há dependências nem etapa de build.

## Tecnologias

- HTML5
- CSS3 responsivo
- JavaScript puro
- Google Fonts: Archivo Black e Space Mono
